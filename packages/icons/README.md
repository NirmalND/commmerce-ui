# @commmerce/icons

Commmerce UI line icons: a 24px grid, 1.6px round stroke, coloured by `currentColor`.

Docs: https://commmerce.com/blog/commmerceui/#icons

```js
import { icons, iconNames } from '@commmerce/icons'; // icons.cart === SVG path data
```

SVG files: `@commmerce/icons/svg/<name>.svg`. In apps, prefer the `<cm-icon name="cart">` element from
`@commmerce/ui`.

Support: support@commmerce.com
