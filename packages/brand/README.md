# @commmerce/brand (internal, not published)

Commmerce logos for Commmerce's own products. Apps built by other developers must not
use these (see the licence).

| File | Use |
| --- | --- |
| `logos/svg/wordmark-black.svg`, `-white.svg` | Product UI: admin header, login, emails. Vector, scales cleanly. No ™. |
| `logos/svg/mark-black.svg`, `-white.svg` | The "M" mark: favicons, app icons, collapsed navigation. |
| `logos/png/wordmark-tm-*.png` | 2025 wordmark with ™ (3283×240). Marketing, documents, large placements. |
| `logos/png/mark-tm-*.png` | 2025 "M" mark with ™. |
| `logos/png/favicon-black-256.png` | 2025 favicon (white mark on black square). |

Rules (from the design system):
- Black wordmark on light grounds, white on black and dark grey. No full stop after the name.
- Minimum height 16px for the wordmark in UI.
- The SVGs come from the 2024 vector set (`Outdo Branding/Commmerce/Commmerce-Logos/SVG`);
  letterforms match the 2025 logos exactly, which add only the ™. When a vector ™ version is
  exported from the source artwork (`16Feb - Commmerce Final Logos2.ai`), replace these.
